📐 AP Physics 1 Formula Sheet ✕

Kinematics

v = v₀ + at
x = x₀ + v₀t + ½at²
v² = v₀² + 2a(x–x₀)
x = x₀ + ½(v+v₀)t

Forces

F_net = ma
f_k = μ_k·N
F_g = mg (g = 9.8 m/s²)
F_s = –kx (Hooke's Law)

Work, Energy, Power

W = Fd·cosθ
KE = ½mv²
ΔPE_g = mgΔh
PE_s = ½kx²
P = W/t = Fv

Momentum

p = mv
J = FΔt = Δp
p_before = p_after
e = 1 (elastic); e = 0 (perfectly inelastic)

Rotation

τ = rF·sinθ
τ_net = Iα
L = Iω
KE_rot = ½Iω²
I_disc = ½MR²; I_rod = ⅓ML²

Oscillations

T_spring = 2π√(m/k)
T_pendulum = 2π√(L/g)
f = 1/T
x(t) = A·cos(2πft)

Fluids

P = P₀ + ρgh
F_b = ρ_fluid·V·g
A₁v₁ = A₂v₂ (continuity)
P + ½ρv² + ρgh = const (Bernoulli)
